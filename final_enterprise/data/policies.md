# S&OP 供应链合规规则库（企业版）

## 1. 预测准确率分级管理
- A 级：预测准确率 >= 85%，维持当前补货策略。
- B 级：70% <= 预测准确率 < 85%，要求每周复盘偏差来源，并优化模型参数。
- C 级：预测准确率 < 70%，触发跨部门协同流程，需提交纠偏计划。

## 2. 风险动作审批红线
- 任何涉及“削减库存 15% 及以上”的建议，必须人工审批。
- 涉及核心 SKU 下架、停采、停产等动作，必须总监级审批。
- 同时涉及缺货率升高与库存削减的组合策略，需双签审批。

## 3. 缺货率与补货策略
- 缺货率 <= 3%：按标准补货节奏执行。
- 3% < 缺货率 <= 5%：提高安全库存系数，重点门店日监控。
- 缺货率 > 5%：触发黄色预警，要求运营与供应链联合处置。

## 4. 审批结论处理规则
- 同意（approved）：可直接进入执行与监控。
- 驳回（rejected）：禁止执行，必须重新提交方案。
- 修改（revise）：限定范围试点执行，并保留复核节点。

## 5. 输出报告规范
- 必须包含数据事实、规则依据、执行动作、风险说明。
- 所有结论都要可追溯到 SQL 查询结果与规则片段。
